# Phone remote

A "Phone remote" card that shows how to use a phone as the TV's remote: the steps, the name the TV goes by on
the network, and QR codes for the Google TV app on Android and iPhone. Any phone on the home Wi-Fi can pair
with the TV's own remote service using the 6-digit code the TV shows; no Google account is needed on the phone.

Tested on a Xiaomi MiTV-MOOR2 (Google TV / Android 11): pairing works with only the on-screen code.

## Permissions

None. The QR codes are bundled images and the TV's name is read from a system setting anyone can read.
No network access, no background service.

## Build and install

As in [the add-ons README](../README.md). The launcher asks once whether to show the card.
